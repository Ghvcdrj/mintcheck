## Что я сделал: MintCheck
Веб-сайт, который проверяет токен на Solana перед покупкой. Вставляете адрес токена, и сайт показывает:
- **Mint authority**: может ли создатель печатать новые токены (если да, это опасно);
- **Freeze authority**: может ли создатель «заморозить» ваши токены, чтобы вы не смогли продать;
- **ловушки Token-2022**: скрытый налог на перевод, «вечный делегат», который может забрать токены из любого кошелька, и т.п.;
- **топ держателей**: сколько процентов у самого крупного кошелька. Пулы и bonding curve отделяются от обычных кошельков по математическому признаку: у PDA-адресов нет приватного ключа, они лежат «вне кривой ed25519»;
- **живую активность**: сколько транзакций было за последнюю минуту, 5 минут и час;
- **давление покупок и продаж** за 5 минут (через Solami Blur);
- **ленту новых токенов и трендов**, где каждый токен сразу проверяется;
- итоговую **оценку 0–100** с объяснением каждого снятого балла.

Дополнительно есть `alerts.py`: Telegram-бот, который пишет «🟢 чистый / 🔴 опасный запуск».

**Статус (25.09, проверено с вашим бесплатным ключом Solami на живом mainnet):**

## Как это работает (чтобы вы могли объяснить на видео)
- `app.py` — сервер на Flask. У него 3 адреса: `/api/status`, `/api/check`, `/api/feed`.
- `solami_client.py` — ходит в Solami. Ключ хранится только на сервере и в браузер не попадает. Есть ограничение скорости: не больше 4 запросов в секунду, на бесплатном тарифе лимит 5.
- `safety.py` — логика оценки без интернета, поэтому её легко тестировать.
- `static/` — страница: HTML, CSS и JavaScript без сборки.
